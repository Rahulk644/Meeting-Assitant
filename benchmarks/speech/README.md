# Speech model benchmark

This harness evaluates candidate speech models through the same native `transcribe-server` binary shipped
by My Assistant. It measures transcript accuracy, model startup, hot inference speed, and process RSS on the
machine running the test. Models and evaluation audio remain outside the repository under
`~/.cache/my-assistant-bench` by default.

Build the pinned native server once before benchmarking: `./stt/transcribe-server/build.sh`.

## Reproducibility and data boundaries

- `catalog.json` pins every runnable weight by Hugging Face revision, byte size, and SHA-256.
- CoSHE-500 is **CC-BY-NC-4.0, evaluation-only**. It must never be used for training or redistributed in a
  release artifact. The extractor records the dataset revision and source-row selection in the manifest.
- CoSHE references use natural mixed Devanagari/Latin script. Its WER is not comparable for a model designed
  to emit all-Roman text. Such runs remain useful for latency and qualitative review, and the report marks
  their score `scoreComparable: false`.
- The scorer preserves Devanagari combining marks. It does not use Whisper's normalizer, transliterate, or
  normalize numbers.
- Private recordings should be placed only in the benchmark cache. Reports can contain transcripts and are
  therefore local/private by default.

## Quick start

```sh
# Verify/download the Roman candidate and the already-installed baseline.
./script/benchmark_speech.sh prepare-models \
  whisper-turbo-q8 apex-hinglish-q8

# Download the pinned public evaluation parquet and extract 24 deterministic clips.
./script/benchmark_speech.sh prepare-data

# Extract all 500 evaluation clips for promotion runs.
./script/benchmark_speech.sh prepare-full-data

# Extract 24 aligned Hindi-speech / human-English FLEURS clips for translation evaluation.
./script/benchmark_speech.sh prepare-translation-data

# Extract a separate 24-clip human-reference English FLEURS transcription control.
./script/benchmark_speech.sh prepare-english-data

# Create deterministic 12-clip synthetic wind and speech-babble stress sets, then pass each through the
# exact Rust resampler/VAD used by dictation. These are failure-boundary tests, not real-world proof.
./script/benchmark_speech.sh prepare-noise-data

# Reproduce the pinned Srota Q6 conversion (large temporary files; needs 6 GB free).
./script/benchmark_speech.sh convert-srota

# Reproduce a pinned Whisper fine-tune conversion. Catalog metadata chooses the base preprocessor, variant,
# quantization, disk floor, and expected output hash; add --clean-source via convert_whisper.py if needed.
./script/benchmark_speech.sh convert-whisper shuja-whisper-medium-hinglish-q5

# Run the shipped baseline and Roman research candidate through the native server.
./script/benchmark_speech.sh run whisper-turbo-q8,apex-hinglish-q8

# Run a resumable three-trial qualification matrix. Each model is passed through the audio policy pinned in
# catalog.json. Fewer than 500 samples / three trials fail closed unless --allow-smoke is passed directly to
# run_matrix.py. Qwen remains an optional research entry and is deliberately absent from this command.
./script/benchmark_speech.sh run-matrix whisper-turbo-q8

# Build a blind 500-item annotation pack. Open the printed annotate.html locally; one person transcribes
# and a different person reviews. No source transcript is exposed to the annotators.
./script/benchmark_speech.sh create-roman-pack

# Discover microphones and capture consented field recordings in the real environment. `capture-real`
# forwards to capture_real_noise.py; see CORPUS_PROTOCOL.md for the required metadata and coverage.
./script/benchmark_speech.sh capture-real list-devices

# Fast unit checks for script-safe scoring.
./script/benchmark_speech.sh test
```

`ASSISTANT_BENCH_CACHE=/another/private/path` changes the cache root. Pass `MANIFEST=/path/to/file.jsonl`
to the wrapper to evaluate a different corpus. A compatible manifest begins with one `corpus_header` JSON
record and then uses `id`, `audio`, `ref_text`, `language`, and `referenceStyle` per sample.

Roman-output comparisons use `derive_references.py` to create an explicitly machine-derived transliteration
proxy; its WER is only an A/B signal. English translation uses FLEURS sentence IDs to align Hindi recordings
with the corresponding human English FLoRes sentence, so its references are not generated by another model.
Ordinary English transcription uses a separate pinned `en_us` FLEURS validation sample with human references;
translation and English ASR scores must never be conflated.
`add_noise.py` deterministically mixes either modulated low-frequency noise or three competing speech clips
at 5 dB SNR. The manifest records the seed, method, source hashes, mix gain, and a warning that synthetic
stress does not establish performance in a real café, street, or windy outdoor recording.

The product-pipeline comparison invokes `preprocess_speech_manifest`, a Rust example that calls the exact
audio module used by the app. It is not a Python approximation. `catalog.json` pins one explicit policy per
runnable model: `vad-compact` concatenates speech frames, `vad-gate` blocks silence but preserves the entire
clip, and `resample-only` is an offline control. Whisper currently qualifies with `vad-compact`; Apex and
Qwen use `vad-gate` because compacting their audio removed useful acoustic/contextual evidence.

`run_matrix.py` enforces 500 samples and at least three trials for promotion evidence, shuffles model order
per trial to reduce ordering/thermal bias, resumes only structurally complete reports, preserves each native
trial log, and reports min, median, max, standard deviation, truncation/degeneration, RSS, speed, and
cross-trial hypothesis instability. Its summary pins the catalog, server, model artifacts, preprocessor,
derived manifests, and randomized trial order.

Human Roman and real-noise procedures live in [`CORPUS_PROTOCOL.md`](CORPUS_PROTOCOL.md). Annotation packs,
recordings, consent mappings, transcript-bearing manifests, and raw reports remain private cache data.

## Promotion gate

A model is not eligible for the product catalog until it:

1. passes the full 500-clip mixed-script evaluation or an equivalent style-matched Roman corpus;
2. passes consented clean, café, traffic, wind, fan, echo, overlapping-speaker, and silence fixtures;
3. records accuracy, hallucination rate, startup, real-time factor, peak memory, energy impact, and recovery;
4. has verified licensing and provenance for both upstream and converted weights; and
5. loads through the pinned production runtime with no benchmark-only code path.

The 24-clip default is an engineering smoke benchmark, not a publishable model-quality claim.
The first aggregate result and its product decision are documented in
[`docs/SPEECH_MODEL_BENCHMARK.md`](../../docs/SPEECH_MODEL_BENCHMARK.md). Raw reports contain transcripts and
must remain in the private cache; commit only aggregate evidence under `results/`.
