# Support

My Assistant is an early macOS beta. Dictation is the primary supported workflow; Meetings is explicitly
beta. There is currently no paid support SLA.

## Before reporting a problem

1. Confirm you are running the newest provided build and note its version.
2. Reproduce once after quitting and reopening My Assistant.
3. Check Settings → General → Permissions and describe which grants are present.
4. Do not attach meeting audio, transcripts, API keys, or screenshots containing private information unless
   you intentionally choose to share them.

Use the GitHub bug template for reproducible product defects. Use a private maintainer channel for security
issues as described in [`SECURITY.md`](SECURITY.md). Discord/Telegram support destinations will be added only
when official links exist; this repository will not invent placeholder contacts.

The diagnostic-export feature is not shipped yet. Until it is, include only the app version, macOS version,
Mac model/chip, affected workflow, exact steps, expected result, actual result, and whether the problem still
occurs after relaunch.
